# LÖSUNG
### Werk GmbH — Industrial Production Management System v2.4

A browser-based puzzle game. No installation required — open the HTML file in any browser.

---

## How to Play

Arrange falling components to fill complete rows and meet your production quota. You have five minutes.

**Controls**

| Key | Action |
|---|---|
| ← → | Move |
| ↑ | Rotate |
| ↓ (hold) | Soft drop |
| Space | Hard drop |

Mobile: on-screen buttons are provided automatically.

---

## About

*LÖSUNG* is a short game (~5 minutes) inspired by two works:

- **Brenda Romero's *Train*** (2009) — an analogue game about complicity and systems
- **Gabrielle Zevin's *Tomorrow, and Tomorrow, and Tomorrow*** (2022) — specifically, the fictional game "Solution" described in Chapter 3, designed by the character Sadie Green

The word *Lösung* means "solution" in German.

The game explores a question that both works share: what does it mean to follow the rules of a system without asking what the system is for?

---

## Technical

Single HTML file. No dependencies, no build step, no server required.

Built with vanilla HTML, CSS, and JavaScript. Audio via Web Audio API.
